# VNA Screenshots

Store VNA display screenshots here for documentation and visual reference.

## Purpose

Screenshots provide:
- Visual confirmation of measurements
- Quick reference without re-importing data
- Documentation for reports and troubleshooting

## Recommended Content

Capture screenshots showing:
- Calibration status/indicators
- Measurement traces with markers
- Scale settings (dB/div, ref level)
- Frequency span and resolution
- Measurement setup (e.g., S11, S21)

## File Naming

Use descriptive names matching the corresponding data files:

Examples:
- `2026-01-04_att_chain_fullband_screenshot.png`
- `2026-01-04_s11_hl2_40m_lpf_screenshot.png`
- `2026-01-04_s21_lpf_40m_screenshot.png`

## Format

- **PNG** preferred (lossless, good compression)
- JPEG acceptable (use high quality setting)
- Resolution: Minimum 800x600, recommend native VNA display resolution

## Tips

- Use VNA's built-in screenshot function if available
- Ensure markers and annotations are visible
- Capture legend/scale information
- Include multiple views if helpful (e.g., Smith chart + log mag)

## Size Considerations

- Keep individual screenshots under 1 MB
- Compress if needed (PNG optimization tools)
- Consider Git LFS if accumulating many large images
